# 指令叠加层 v1.3

双击`Start.cmd`。需要Node.js 24或更新版本、FFmpeg/FFprobe以及Edge或Chrome。可自动查找上级翻译项目现有的FFmpeg。在其他电脑上，请将FFmpeg/FFprobe及其所需DLL放入`tools`或配置PATH。此源码文件夹不包含这些运行环境。

1. 选择已剪辑的原视频，直接关联原文件，不创建视频副本。移动或重命名原文件后需重新选择。
2. 选择最多3名队员，可收藏多支队伍。初始列表含62名角色，其他角色可通过“添加头像”注册名称和图片。
3. 观看视频并用键盘记录。短按记录普通输入，长按标记Hold。暂停时也可标记Hold，结束帧需手动调整。
4. 从右侧列表选择指令，编辑自定义文字、Hold和起止帧，或删除。拖动时间轴不会更改编辑对象。
5. 保存`.zzzoverlay`项目并导出。最近的工作会自动保存并在下次启动时恢复，项目文件不包含原视频。

Space播放/暂停，方向键逐帧，1/2/3选择队员，A/S/D为普通攻击/闪避/招架换人，W/E/Q/Z为强化特殊技/特殊技/终结技/连携技，Delete删除，Ctrl+Z / Ctrl+Shift+Z撤销/重做。文本输入时不会触发指令快捷键，按键和Hold判定时间可在设置中修改。

同一角色的连续操作最多3个自动合并。从第2或第3个操作前分行时，后续其他行保持不变。首个操作不允许再分行。仅在同一角色且合计不超过3个操作时允许与上一行合并。删除、分行和合并均可撤销。

较重的视频可创建轻量720p预览，仅降低播放分辨率，保留原时间轴和最终输出尺寸。首次转换需要时间。

默认导出仅含显示区域的透明ProRes 4444 MOV。3840×2160视频从1024×512起，文字较长时自动扩展；保留时长和所选帧率。取消区域裁剪后输出原视频完整分辨率的透明画面。也可输出PNG序列，将`frames`按`timing.json`中的帧率导入。

在FilmCraft/EffectCraft中将叠加层放在原视频上方并对齐起点。`timing.json`中的`placement`为原视频左上坐标。使用中心坐标的编辑器应设置为`x + width/2`, `y + height/2`。导出后的文字已合成在视频中，需要通过项目修改并重新导出。

已用4K样片验证记录、删除/撤销、预览、自动保存及MOV/PNG输出，并检查MOV透明度、编码、尺寸和帧数。尚未在FilmCraft/EffectCraft内部直接验证导入。指令图标原图为48×48，提高输出分辨率不会增加原图细节。出处见[ASSETS.md](ASSETS.md)。所有处理均在本机进行，关闭启动窗口即可结束。

## v1.1更新

添加菲欧妮、维琳娜和蕾米埃尔的默认圆形头像。旧项目也会补充这些角色，保留原队伍、文字和记录。新增分行滑动、淡入淡出和指令高亮过渡（默认180毫秒）。预览、MOV和PNG使用同一视频时间动画，可在设置中关闭或调整为0～500毫秒；向后跳转也会还原相同动画帧。

## v1.2更新

直接关联原视频，`data/uploads`仅保存本地关联信息及主动创建的720p预览。项目文件不包含原视频路径，重复选择也不会复制视频。在设置中点击“删除全部720p预览”可清除此应用的所有预览，并切回原视频，保留原视频和指令记录。

预览高度适应窗口，使播放、时间轴及输入按键保持可见，右侧独立滚动。连接符默认为`→`，选择行内第2或第3个指令可仅将其前面的连接改为`+`，行首不显示连接符。换人指令可选白色/黄色图标，新输入的默认颜色可在设置中选择。黄色HUD原图为88×86，外圈缺口与参考图不同。长按结束帧记录松开按键的时点，目前仅显示Hold文字，不用于时长动画。

播放按钮旁新增音量与静音控制，下次启动时保留。

## v1.3更新

已补齐正式版3.3全部62名角色的圆形头像及韩语、简体中文、日语、英语名称，语言选择新增地球图标。在页面底部点击“检查更新”，再点击“安装更新”即可更新并重启。请先完成导出及预览任务。个人项目、原视频、设置和输出均保留，旧程序文件备份于 `runtime/update-backup-*`。

Windows首次安装：下载发布ZIP并解压，准备 [Node.js](https://nodejs.org/) 24或更新版本及 [FFmpeg](https://ffmpeg.org/download.html)，然后运行 `Start.cmd`。
