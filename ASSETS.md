# Artwork sources

Game artwork belongs to HoYoverse. The program code and exported custom annotations do not change that attribution.

- Command glyphs: public game asset mirror, `https://static.nanoka.cc/assets/zzz/`, filenames recorded in `public/assets/sources.json`.
- Portraits: Enka.Network public image CDN, with filename mappings and localized names from [EnkaNetwork/API-docs](https://github.com/EnkaNetwork/API-docs/tree/master/store/zzz).
- Reference UI icon list: [Zenless Zone Zero Wiki](https://zenless-zone-zero.fandom.com/wiki/Category:UI_Icons). Wiki original-file downloads were inaccessible during preparation; files are not described as downloaded from the wiki.

The six command glyph originals are 48×48. The special attack uses the EX special glyph desaturated at draw time, matching the shared shape; it is not a separately recovered original. QTE is the current chain-attack glyph. A future asset update can replace these files without changing the project’s timing data. Agent portraits use the supplied circular originals with no added frame.

The catalog contains all 62 agents released in Version 3.3 as of November 25, 2026. The four-language names use the public live-version data, and the base circular portraits are mapped using the Enka avatar list. Unreleased agents and alternate skins are excluded. Other portraits can be added locally by the user. UI language changes do not translate custom names, titles or annotations.

The yellow switch option is an unmodified 88×86 public HUD image from [GenshinLab](https://genshinlab.com/zenless-zone-zero/ellen-build/) ([original image](https://genshinlab.com/wp-content/uploads/Switch-e1705240619857-1.webp)). Its outer ring has different gaps from the supplied six-segment reference; an exact original for that reference has not been located. Existing records retain the white icon.
