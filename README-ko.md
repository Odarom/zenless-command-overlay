# 커맨드 오버레이 v1.3

## 실행

이 폴더의 `Start.cmd` 또는 상위 폴더의 `커맨드-오버레이.cmd`를 더블클릭하세요. 열린 브라우저에서 작업합니다. 실행 창을 닫으면 프로그램이 종료됩니다.

Node.js 24 이상, FFmpeg·FFprobe, Microsoft Edge 또는 Chrome이 필요합니다. 이 프로젝트에서는 기존 영상 프로그램의 FFmpeg를 자동으로 찾습니다. 다른 PC에서는 FFmpeg와 FFprobe를 `tools` 폴더에 설치하거나 PATH에 등록하세요. 공유 빌드인 경우 FFmpeg에 필요한 DLL도 함께 두어야 합니다. Node.js와 FFmpeg 실행 파일은 이 소스 폴더에 포함하지 않았습니다.

## 작업 순서

1. 길이를 정해 잘라둔 원본 영상을 선택합니다. 원본 경로를 직접 연결하며 영상 복사본을 만들지 않습니다. 원본을 이동하거나 이름을 바꾸면 다시 선택하세요.
2. 파티에 최대 3명을 선택합니다. `파티 저장`으로 여러 파티를 즐겨찾기에 보관할 수 있습니다. 기본 목록은 62명이며, 다른 캐릭터는 `초상화 추가`에서 이름과 이미지를 등록하세요.
3. 영상을 재생하거나 프레임을 옮기며 키보드로 기록합니다. 짧게 누르면 일반 입력, 길게 누르면 Hold가 붙습니다. 정지 중에도 Hold 표시를 넣을 수 있으며, 홀드 끝 프레임은 직접 조정합니다.
4. 오른쪽 목록에서 편집할 커맨드를 선택합니다. 영상 탐색은 편집 선택을 바꾸지 않습니다. 보조 문구, Hold, 시작·끝 프레임을 수정하거나 삭제할 수 있습니다.
5. 프로젝트를 파일로 저장하고 오버레이를 내보냅니다. 최근 작업은 자동 저장되어 다음 실행 때 복원됩니다. `.zzzoverlay` 프로젝트에는 원본 영상 자체가 포함되지 않습니다.

무거운 영상은 `가벼운 720p 미리보기 만들기`를 사용하세요. 재생용 해상도만 낮추며 원본의 시간축과 최종 출력 크기는 유지합니다. 처음 변환할 때는 시간이 걸립니다.

## 기본 조작

| 키 | 기능 |
|---|---|
| Space | 재생 / 정지 |
| ← / → | 1프레임 이동 |
| 1 / 2 / 3 | 입력할 파티 캐릭터 선택 |
| A / S / D | 일반공격 / 회피 / 패링·교체 |
| W / E / Q / Z | 강특 / 일특 / 궁극기 / 콤보스킬 |
| Delete | 선택한 커맨드 삭제 |
| Ctrl+Z / Ctrl+Shift+Z | 되돌리기 / 다시 실행 |

글자 입력란에서는 커맨드 키가 작동하지 않습니다. 입력 키와 Hold 판정 시간은 `표시 / 단축키 설정`에서 변경할 수 있습니다.

같은 캐릭터의 연속 조작은 최대 3개씩 자동으로 묶습니다. 두 번째·세 번째 커맨드 앞에서 줄을 나누면 다른 줄은 유지됩니다. 첫 커맨드에서는 나누기가 비활성화됩니다. `이전 줄과 합치기`는 같은 캐릭터이고 합쳐서 3개 이하일 때만 가능합니다. 삭제·분리·합치기는 되돌릴 수 있습니다.

## 내보내기와 편집 프로그램

- 기본: 표시 영역만 담은 투명 MOV, ProRes 4444 + 알파. 3840×2160 영상에서는 1024×512부터 시작하고 문구가 길면 자동으로 넓힙니다. 원본의 기준 FPS와 전체 길이를 유지합니다.
- `표시 영역만 출력`을 끄면 원본 해상도의 전체 투명 화면으로 내보냅니다.
- 대안: 투명 PNG 연속 이미지. 출력 폴더의 `frames`를 이미지 시퀀스로 가져오고 `timing.json`에 적힌 FPS를 지정하세요.
- `출력 폴더 열기`에서 MOV·PNG와 크기·FPS·배치 정보를 확인할 수 있습니다. 결과는 `output/<작업 번호>`에 보관됩니다.
- FilmCraft / EffectCraft에서 원본 위 트랙에 올리고 시작점을 맞추세요. 잘라낸 오버레이의 배치는 `timing.json`의 `placement`에 원본 기준 왼쪽 위 좌표로 기록됩니다. 중심점을 쓰는 편집기에서는 `x + width/2`, `y + height/2`가 같은 배치입니다.
- 글자·초상화·아이콘은 최종 영상에 합쳐집니다. 나중에 바꾸려면 프로젝트에서 수정 후 다시 내보내세요.

4K 시험 영상으로 기록·삭제·복구·미리보기·자동 저장과 MOV/PNG 출력을 검증했습니다. MOV의 ProRes 4444, 투명도, 해상도, 프레임 수를 확인했습니다. FilmCraft / EffectCraft 프로그램 내부에서의 가져오기는 아직 직접 확인하지 않았습니다.

원본 커맨드 아이콘은 48×48입니다. 출력 해상도를 높여도 이 원본의 세부 묘사가 늘어나지는 않습니다. 원형 초상화와 커맨드 아이콘 파일은 `public/assets`에 분리되어 있습니다. 자세한 출처는 [ASSETS.md](ASSETS.md)를 참고하세요.

## v1.1 업데이트

- 피닉스·벨리나·레미엘의 기본 원형 초상화를 추가했습니다. 예전 프로젝트를 열어도 목록에 자동 보충되며 기존 파티·문구·기록은 유지합니다.
- 기본 180밀리초의 줄 이동·페이드와 현재 아이콘 강조 전환을 추가했습니다. 미리보기와 MOV·PNG 출력에 동일하게 적용됩니다.
- `표시 / 단축키 설정`에서 전환을 끄거나 0~500밀리초로 조절할 수 있습니다.
- 전환은 영상 시간으로 계산하므로 뒤로 탐색해도 같은 프레임에서 같은 모양을 보여줍니다.

## v1.2 업데이트

- 원본 파일을 직접 연결합니다. `data/uploads`에는 연결 정보와 요청한 720p 미리보기만 저장합니다. 같은 원본을 다시 선택해도 영상 복사본이 생기지 않습니다. 프로젝트 파일에는 원본 경로를 넣지 않습니다.
- 표시 / 단축키 설정의 `720p 미리보기 일괄 삭제`로 이 앱의 미리보기를 모두 지울 수 있습니다. 현재 미리보기로 재생 중이면 원본으로 돌아갑니다. 원본 영상과 기록은 보존합니다.
- 영상 높이도 창에 맞춰 재생·타임라인·입력 키를 함께 볼 수 있게 했습니다. 오른쪽 편집 영역은 별도로 스크롤합니다.
- 기본 연결은 `→`입니다. 같은 줄의 두 번째·세 번째 커맨드를 선택하고 `앞 커맨드와 연결`에서 해당 연결만 `+`로 바꿀 수 있습니다. 첫 커맨드에는 연결 기호가 없습니다.
- 교체 커맨드는 편집 영역에서 흰색/노란색 아이콘을 선택합니다. 새로 기록할 교체의 기본 색은 표시 / 단축키 설정에서 고릅니다. 노란 원본은 88×86이며 참고 이미지와 테두리 간격은 다릅니다.
- 홀드 끝 프레임은 키를 놓은 시점의 기록입니다. 현재 표시 길이나 애니메이션에는 사용하지 않고 Hold 글자만 표시합니다.

- 재생 버튼 옆에 영상 볼륨과 음소거를 추가했습니다. 다음 실행에도 유지합니다.

## v1.3 업데이트

- 정식 3.3 버전 전체 62명의 원형 초상화와 한국어·중국어(간체)·일본어·영어 명칭을 제공합니다.
- 언어 선택에 지구본 아이콘을 추가했습니다.
- 화면 하단의 **업데이트 확인**에서 새 버전을 확인하고 **업데이트 설치**를 누르면 프로그램을 업데이트하고 재시작합니다. 출력·미리보기 작업을 마친 뒤 설치하세요. 개인 기록, 프로젝트, 원본 영상, 설정과 출력 파일은 유지됩니다. 이전 프로그램 파일은 `runtime/update-backup-*`에 보관합니다.
- 첫 설치: GitHub Releases의 ZIP을 내려받아 압축을 풀고, [Node.js](https://nodejs.org/) 24 이상과 [FFmpeg](https://ffmpeg.org/download.html)를 준비한 뒤 `Start.cmd`를 실행하세요. Windows에서 사용합니다.
