# Zenless Command Overlay v1.3

[한국어](README-ko.md) · [English](README-en.md) · [日本語](README-ja.md) · [简体中文](README-zh-CN.md)

Watch a trimmed video, record game commands, and export a transparent overlay for your video editor.

Start: double-click `Start.cmd`, or run `node server.mjs --open`.

No API key or account is required. This application runs locally and does not upload your video to a remote service.

Source artwork information: [ASSETS.md](ASSETS.md). Verified sample: [examples/verification.json](examples/verification.json).

Videos are linked directly without a copy. Use settings to delete all generated 720p previews. Window-fit preview, per-connection `→`/`+`, and white/yellow switch icons are available in v1.2.

**[Download the latest Windows release](https://github.com/Odarom/zenless-command-overlay/releases/latest)**. Includes all 62 live agents (Version 3.3), four UI languages, a globe language selector, and in-app update installation. See the localized instructions for prerequisites. Unofficial fan tool; game artwork belongs to HoYoverse.
