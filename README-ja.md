# コマンドオーバーレイ v1.3

`Start.cmd`をダブルクリックします。Node.js 24以上、FFmpeg/FFprobe、EdgeまたはChromeが必要です。親フォルダーの翻訳プロジェクトにあるFFmpegを自動検出します。別のPCでは実行ファイルと必要なDLLを`tools`に置くかPATHに登録してください。このソースには実行環境を同梱していません。

1. 編集済みの元動画を選択します。コピーを作らず元ファイルを直接参照します。移動・改名した場合は再選択してください。
2. 最大3人のチームを選び、お気に入りとして保存できます。初期一覧は62人です。他のキャラクターは「肖像を追加」から名前と画像を登録してください。
3. 動画を見ながらキーで記録します。短押しは通常入力、長押しはHold表示です。停止中もHold表示を指定できますが、終了フレームは手動で調整します。
4. 右側の記録を選び、補助テキスト・Hold・開始/終了フレームを編集または削除します。動画のシークでは編集対象は変わりません。
5. `.zzzoverlay`を保存し、オーバーレイを出力します。最新作業は自動保存され、次回起動時に復元されます。プロジェクトに動画本体は含まれません。

Space：再生/停止、矢印：1フレーム、1/2/3：キャラクター、A/S/D：通常攻撃/回避/パリィ・交代、W/E/Q/Z：強化特殊/特殊/終結/連携、Delete：削除、Ctrl+Z / Ctrl+Shift+Z：元に戻す/やり直す。文字入力中は操作キーが発動しません。キーとHold判定時間は設定で変更できます。

同じキャラクターの連続操作を最大3つずつ自動でまとめます。2番目・3番目の前で分割しても他の行は維持されます。行の先頭では分割できません。同じキャラクターで合計3つ以下の場合のみ前の行と結合できます。削除・分割・結合は元に戻せます。

重い動画には軽量720pプレビューを作成できます。元動画の時間軸と最終出力サイズは維持されます。初回変換には時間が必要です。

基本出力は表示領域だけを切り出した透過ProRes 4444 MOVです。3840×2160動画なら1024×512から始まり、長文に応じて拡張します。長さと基準FPSを維持します。領域出力をオフにすると元動画と同じ解像度です。PNG連番も出力可能で、`frames`を`timing.json`のFPSで読み込みます。

FilmCraft/EffectCraftで元動画の上に置き、開始点を合わせます。`timing.json`の`placement`は元動画上の左上座標です。中心座標を使う場合は`x + width/2`, `y + height/2`です。出力後の文字は動画に焼き込まれるので、変更時はプロジェクトから再出力します。

4Kサンプルで記録・削除/復元・プレビュー・自動保存・MOV/PNG出力と、MOVの透過・コーデック・寸法・フレーム数を検証済みです。FilmCraft/EffectCraft内部での読み込みは未確認です。操作アイコン原本は48×48で、拡大しても原本の細部は増えません。[ASSETS.md](ASSETS.md)を参照してください。処理はこのPC内で行います。起動ウィンドウを閉じると終了します。

## v1.1更新

フィオニー・ヴェリナ・レミエールの標準円形肖像を追加しました。既存プロジェクトにも一覧を追加し、チーム・文字・記録を保持します。行の移動とフェード、アイコン強調の切替を追加しました（標準180ms）。プレビューとMOV・PNGは同じ動画時間に基づいて動きます。設定で無効化または0～500msに変更でき、巻き戻しても同じフレームを再現します。

## v1.2更新

元動画を直接参照し、`data/uploads`には接続情報と任意の720pプレビューだけを保存します。プロジェクトファイルには元動画のパスを含めません。同じ元動画を再選択してもコピーは作りません。設定の「720pプレビューを一括削除」でこのアプリのプレビューをすべて削除し、元動画に戻せます。元動画と操作記録は保持します。

動画の高さを画面に合わせ、再生・タイムライン・操作キーを表示します。右側は個別にスクロールできます。接続は標準で`→`です。行の2番目・3番目の操作を選び、その直前だけ`+`に変更できます。行頭には接続記号を表示しません。交代は白/黄色のアイコンを選べ、新規入力の標準色は設定で変更できます。黄色の原画像は88×86で、参照画像とは外周の切れ目が異なります。Hold終了フレームはキーを離した時点の記録で、現状はHold文字だけを表示し、時間によるアニメーションには使いません。

再生ボタンの隣に音量とミュートを追加し、次回起動時にも保持します。

## v1.3更新

正式版3.3の全62名に円形肖像と韓国語・簡体字中国語・日本語・英語の名称を追加しました。言語選択には地球アイコンがあります。画面下部の「更新を確認」から「更新をインストール」を選ぶと更新して再起動します。出力やプレビュー作成を終了してから更新してください。個人のプロジェクト・元動画・設定・出力は保持され、旧プログラムは `runtime/update-backup-*` に保存されます。

Windowsでの初回導入：リリースZIPを展開し、[Node.js](https://nodejs.org/) 24以上と[FFmpeg](https://ffmpeg.org/download.html)を用意して `Start.cmd` を実行します。
